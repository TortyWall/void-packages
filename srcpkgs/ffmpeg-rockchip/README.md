ffmpeg-rockchip

FFmpeg with Rockchip MPP hardware acceleration support.

Installation

This package is installed under /opt/ffmpeg-rockchip and does not replace or overwrite the system-wide FFmpeg 6 installation.
The FFmpeg binaries (ffmpeg, ffprobe, and ffplay) and associated libraries are kept separate from the system-wide installation.

To use this build, invoke the binaries directly:

/opt/ffmpeg-rockchip/bin/ffmpeg
/opt/ffmpeg-rockchip/bin/ffprobe
/opt/ffmpeg-rockchip/bin/ffplay

This allows ffmpeg-rockchip to coexist with the system-wide FFmpeg installation.
